# Commons UX review (code-read; /home/claude/commons-app, read-only)

## 1. Top findings, ranked by user impact

**1. A refused post/reply wipes the body.** `src/core/ui/action-form.tsx:14` uses `<form action={submit}>`; React 19 resets uncontrolled fields when the action settles, including on `{ error }`. A 50,000-char build log refused `RATE_LIMITED` ("Try again in 58 s") or `INPUT_INVALID` is gone. Hurts posters most. Fix (clone-owned, `ActionForm` is template-owned): a `ForumForm` wrapper in `src/components/` that captures `FormData` in `onSubmit` into state and re-renders children with `defaultValue`s keyed on attempt count; or return `{ error, values }` from `refused()` and echo them.

**2. Voting is hidden behind a `<details>` disclosure.** Thread page `p/[post]/page.tsx:75-84` and `:182-189`: ▲/▼ live inside `<summary>Reply, vote, report…</summary>`, collapsed by default. A reader must open a disclosure per comment to vote, and the redirect after a vote (`actions.ts:108`, no `#anchor`, no `sort`/`page`) reloads the page collapsed and scrolled to the top. The buttons also never show the viewer's current vote (`thread()` in `src/forum/view.ts:75` never reads `Vote` for `me`), so toggle/switch semantics (D-29) are invisible. Hurts readers. Fix: render the vote form outside `<details>`, add `aria-pressed`/a filled glyph from a `myVotes` map, and redirect to `${postPublicId}?sort=&page=#${commentPublicId}` (reply already does, `actions.ts:80`).

**3. `BANNED_UNTIL` drops the lift time.** `actions.ts:31` maps it to "Your account is banned from posting for now." while `src/forum/actions.ts:31` puts the epoch in `e.message`, and D-14/task 4.2 promise "with the lift time". Hurts a banned member (and the mod explaining it). Fix: `Banned until ${when(new Date(Number(e.message) * 1000))}`.

**4. Other refusal copy that reads as a bug.** Duplicate report surfaces as "Check the form: you already reported this (INPUT_INVALID)" (`moderation.ts:53` + `actions.ts:33`). `SELF_VOTE` says "your own post" on comments (`actions.ts:107`). `WRITE_ONCE` and `TREE_INVALID` are raw. `GATED_DOWNVOTE` opens with "Recorded, not counted", which asks the user to understand the vote-event log. Fix: give already-reported its own code/message; "Your downvote wasn't counted: accounts need 24 h and 3 contributions to downvote."

**5. The hot score is printed to readers.** `p/[post]/page.tsx:168`: "hot 14650.68 (ranked N min ago)". D-9: the score is "shown only in the eval". Fix: drop it, or render behind `isMod`.

**6. `ago()` is minutes-only.** `src/components/forum.tsx:16`: a week-old snapshot reads "ranked 10080 min ago"; a future `rankedAt` (DEMO.md ranks at 2026-11-05) reads "0 min ago". Fix: min/h/d units and a `<time datetime>` with the absolute value.

**7. Board page has no pagination and the compose form is at the bottom.** `boardPosts` (`view.ts:58`) `findMany` with no `take`; `[board]/page.tsx:56` puts "New post" under ~80 posts. Empty state `:42` says "Nothing here under this sort." even for an empty board. Fix: `take 50` + the same page nav the thread uses; a "New post" jump link in the breadcrumb row; distinguish "No posts yet" from an empty Top-today window.

**8. Mobile.** `commons.css:14-15`: each nesting level costs 2 rem; at depth 6 on a 360 px phone the body is ~170 px wide. `.votes button { padding: 0 0.4rem }` gives sub-24 px targets. `<input size={60}>` (`[board]/page.tsx:60`) forces ~480 px intrinsic width; the 6-column mod-log `<table>` has no overflow wrapper. Fix: `@media (max-width: 40rem) { ol.thread ol { margin-left: .5rem; padding-left: .5rem } }`, `min-height: 2.5rem` on vote buttons, `width: 100%` instead of `size`, `overflow-x: auto` wrapper on tables.

**9. Mod queue ergonomics.** `mod/page.tsx`: no "Ban author" or "Lock thread" on a case (the mod must leave for the profile page), no filter by kind/reason, log capped at 50 with no paging (`:41`), and `authorHistory` (`:37-39`) counts reports on the author's *posts* only, omitting comments, so a comment spammer shows "0 reports". Fix: a `handle` + `moderateUser` form inline per case; include `nodeKind: 'COMMENT'`; `?page=` on the log.

**10. Report "Something else (say what)" has nowhere to say it.** `rules/moderation.json` label vs `ReportForm` (`p/[post]/page.tsx:121-139`): the `detail` field is accepted by the schema (`actions.ts:125`) but never rendered. Fix: a `<textarea name="detail" maxLength={2000}>`.

**11. Permalink "Back to the thread".** `c/[comment]/page.tsx:55` links `#${comment}`; if the comment sits below the depth cut or on page 2 the anchor is not on the page. Fix: compute the page from `order`, or link to the nearest top-level ancestor.

**12. Wayfinding.** Breadcrumb on the board page ends with a dangling "›" (`[board]/page.tsx:26`); no board name in the permalink crumb; no page `<title>` on thread/board/profile (`metadata` only on Boards and Search). Nav mixes forum links with "Delete org" at equal weight (`layout.tsx:20`).

## 2. Missed or should add

- **Author delete.** Status `deleted` exists (D-13) but no action produces it; `actions.ts` has no delete. Posters cannot remove their own content. **S**
- **Edit history for moderators** (P0-6: "visible to mods"). `EditHistory` is written; no page reads it. **S**
- **Comment collapse / reply count per subtree.** Deep homelab troubleshooting threads need "[-] 14 replies". Pure markup `<details>` keeps the no-JS rule. **S**
- **"Mine" vote state and vote toggle feedback** (see #2). **S**
- **Board descriptions / rules** on the board list and compose form (which board for "is this SBC good"?). **S**
- **Pagination on profile** (`take: 20` with no "more", `view.ts:110`). **S**
- **Search filters**: by board, posts-vs-comments, and a title line on comment hits (`search/page.tsx:39-45` shows a bare 120-char slice). **M**
- **Mod-side "why am I here" on a case**: show the reporter handles/detail text, not just count + reasons. **S**
- **Young-account notice on the compose form** ("new accounts: 1 post/hour, 2 comments/min") read from `rules/limits.json`, so the limit is explained before it fires. **S**
- **Inline image preview in markdown** for the uploaded attachment (currently only an `<ul>` under the post). **M**
