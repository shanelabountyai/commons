# Phase 2 — Schema + votes + ranking job (first database writes)

Written at the Phase 1 gate (2026-10-29) for Shane's review. Not started. Phase 1's engines stay pure; Phase 2 puts a database under them. Exit bar: **the fixture loads into Postgres through the tree module, the one-vote constraint holds at the database, `votes:verify` is clean after the fixture's full event log, the ranking job reproduces `engine:eval`'s orderings from stored rows, and the ADR-001 measurement is repeated on the real schema on CI's Postgres 17.**

- [ ] **2.1 Schema.** Prisma models in `prisma/schema/commons.prisma`: `Board`, `Post`, `Comment` (with `path`, `depth`, `status`, `removedById`), `Vote` (one current row per voter per node, D-29), `VoteEvent` (append-only), `BrigadeSignal` (D-31), `EditHistory`, `RankSnapshot` (`ranked_at`, hot, best, net per node). Migration hand-written (`migrate dev` cannot run in the sandbox); CI's `migrate diff` proves history = schema (port Quorum's step). The first Commons migration also **drops the three billing tables** (D-20). `@@unique([voterId, nodeId])` on `Vote` (non-negotiable 4). *Acceptance:* `prisma validate`; migration applies on a fresh database; `foundation:drift` clean.
- [ ] **2.2 Append-only triggers.** `VoteEvent`, `EditHistory` and (Phase 4) the mod log reject UPDATE/DELETE via triggers in the clone migration (port Quorum D-19 SQL). *Acceptance:* a test UPDATE and DELETE each fail.
- [ ] **2.3 Tree writes.** `src/tree/write.ts` (the only writer): `createComment(postId, parentId)` computes the path from the parent inside one transaction with a per-parent advisory lock, so two replies at once get different ordinals. *Acceptance:* 50 concurrent replies to one parent get 50 distinct segments; a cross-post parent is refused `TREE_INVALID`.
- [ ] **2.4 Fixture load.** `npm run commons:load -- --org <slug>`: users, boards, posts, comments (through 2.3), then every vote event through the vote path, write-once per org. *Acceptance:* the stored paths equal `assignPaths` for every post; counts equal `expected_counts.csv`.
- [ ] **2.5 Vote path + cache + `votes:verify`.** Casting applies V-1..V-4 live and writes `Vote` + `VoteEvent` + the denormalized counts in one transaction; the D-31 detector runs in the same transaction on a `GATED_DOWNVOTE` and writes at most one `BrigadeSignal` per node per window. Replies under a removed node are refused `PARENT_REMOVED` (D-30, in 2.3). `npm run votes:verify` recomputes counts from `Vote` rows and from the event log and diffs both against the cache. *Acceptance:* clean after 2.4; a hand-edited count is reported; the fixture's `P-BRIGADE` yields exactly one signal.
- [ ] **2.6 Ranking job.** `npm run rank:recompute` writes `RankSnapshot` with `ranked_at` using the pure engine; the foundation cron registers it every `recompute.interval_seconds`. *Acceptance:* the snapshot's orderings equal `expected_post_order_*.csv` and `expected_comment_order_best.csv` at `NOW`.
- [ ] **2.7 Edit windows + history.** Edit inside `edit_window_seconds` with no mark; after, an `edited` mark; every edit a row (P0-6). *Acceptance:* boundary at exactly 900 s pinned by a test.
- [ ] **2.8 ADR-001 re-measured on CI.** The same four queries against the Prisma tables on Postgres 17 in CI, numbers appended to the ADR. *Acceptance:* if the closure table wins by more than 2× on the thread fetch, stop and show Shane before Phase 3.
- [ ] **2.9 `engine:eval:db`.** Phase 1's eval re-run from the database: load, cast, recompute, export, diff against the same 12 expected files. *Acceptance:* 0 differences; CI runs it.
- [ ] **2.10 Phase 2 gate.** `docs/EVAL.md` §Phase 2; NEXT.md; `docs/phase-3-tasks.md` (XSS fixture set **before** the renderer, sanitizer dependency proposal, limits storage on the foundation's counter or a sliding-window table, spam-bot and normal-user suites, upload limits) written and review requested.

**Decided 2026-10-29 (D-28..D-31):** materialized path confirmed; `Vote` current row + event log; removed subtree votable not replyable; brigade signal recorded, not acted on. Nothing open before 2.1. Phase 2 starts on Shane's go.
